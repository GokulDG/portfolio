# Beyond the Interface

The personal portfolio of Gokulkumar K, a full-stack and backend engineer.

It is a single scrolling page that introduces who I am, the systems I build, the tools I work with, how I approach a problem, and how to get in touch. The design is editorial and quiet, with motion used to explain ideas rather than decorate them.

## Built with

Next.js, TypeScript, GSAP and Three.js.

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
